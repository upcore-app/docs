Issues and pull requests are welcome. What follows is what a reviewer will look
for.

## Run the commands

```bash [Terminal]
bun install        # after a pull that changed package.json
bun run dev        # migrate, then dev server
bun run build      # production build (.output)
bun run db:migrate # apply migrations to the configured database
bun run openapi    # regenerate openapi.json — after every /api/v1 change
bun run typecheck  # vue-tsc -b --noEmit
```

::warning
`-b` on the typecheck is required. Without it, project references are skipped and
nothing is checked at all.
::

## Find your way around

```
app/            Nuxt app — pages, components, composables (UI copy is German)
server/api/     admin API (session-authenticated) and /api/v1 (API keys)
server/db/      two schema twins (sqlite/pg) + numbered SQL migrations
server/utils/   validation, monitors, API key handling, CIDR matching
shared/         types shared between client and server
scripts/        migration runner, OpenAPI generator
```

## Mind the invariants

These are the things a passing typecheck will not catch.

::steps{level="3"}

### Two databases, one codebase

Every query is awaited, every table is defined twice, the SQL avoids SQLite-only
functions, and aggregates are cast so Postgres does not hand back strings. Read
`server/db/config.ts` and `server/utils/db.ts` before touching `server/db/` or
adding a query.

See [Databases](/operations/databases) for the full list.

### The OpenAPI contract

`openapi.json` is a **build artifact**. Never edit it by hand: change the zod
schema in `server/utils/api/schemas.ts` and the route entry in
`server/utils/api/openapi.ts`, run `bun run openapi`, and commit the regenerated
file with the code change.

CI checks that it is current.

### The migration rules

A schema change means a new numbered `.sql` file in **both**
`server/db/migrations/sqlite/` and `.../postgres/`, plus the matching column in
both schema twins. Never edit a migration that has already been applied.

CI checks that migrations apply — and re-apply idempotently — against both
SQLite and PostgreSQL.

### Language

Code and comments are English. User-facing copy goes through i18n
(`i18n/locales/`) in **both** German and English.

### New background intervals are leased

`acquireLease(job, ttl)` at the top of the tick that owns the schedule, and
`holdsLease(job)` in the passes that ride along on it. An unleased timer runs
once per replica. See [Running more than one container](/operations/scaling).

### New root tables go into the tenant delete

Nothing cascades from the organization row itself. A root table missing from
`deleteOrganization()` makes deleting a tenant fail on a foreign key — or worse,
leave its rows behind.

::

## Before you open a PR

```bash [Terminal]
bun run typecheck
bun run openapi:check
```

::note
`bun.lock` is the lockfile. There is no `package-lock.json`, and adding one back
would give the image and a developer's machine two different dependency trees.
Install with `bun install`, add packages with `bun add`.
::
