A status page is a public URL — `/status/<slug>` — that shows a chosen set of
monitors. You can have any number of them: one for customers, one for the
internal platform, one per product. A monitor may appear on several.

## Create a page

Under **Status pages** in the admin UI. A page needs a slug and a set of
monitors; everything else has a default.

Monitors can be put into groups on the page, so a reader sees *API*, *Web* and
*Workers* rather than a flat list of nineteen names.

::note
Status page slugs are unique across the whole instance.
A public page is linked to from outside, so `/status/<slug>` has to name exactly
one page whatever host it is opened on.
::

## Design it

The design lives in the admin UI, not in a stylesheet you have to deploy:

- **Logo** — uploaded, stored next to the database.
- **Primary colour**, background, card and text colours.
- **Font** — nine self-hosted faces (Inter, Lexend Deca, Montserrat, Open Sans,
  Roboto, Nunito, Lato, Ubuntu, Poppins). Nothing is loaded from a Google CDN.
- **Corner radius**.
- **Custom CSS**, for whatever the fields above do not reach.

A page branded light gets a light page — the admin UI is dark-only, the public
pages are not.

## Set what it says

| | |
| --- | --- |
| Footer text | Free text under the monitors. |
| Imprint and privacy links | Where a jurisdiction needs them. |
| "Powered by upcore" | Can be removed. |
| SEO and OpenGraph tags | Per page — title, description, image. |
| Heartbeat history window | How far back the bars go on the public page. |
| Locations | Whether the page names the outposts a monitor is checked from. |

::note
Naming the locations is off by default. Which probes exist is infrastructure, and
publishing it should be a decision rather than a side effect of using outposts.
The public view is deliberately narrower than the admin one: a name, a city, a
country and the last round trip — no check messages, which can name an internal
target.
::

## Speak the visitor's language

The public pages are bilingual, German and English, selected per visitor. The
locale rides on a cookie rather than a URL segment, so `/status/<slug>` stays the
address you handed out — no `/de/` appears in a link somebody already bookmarked.

## Show one monitor somewhere else

Two ways, for two different places:

- **`/embed/<slug>/<monitor>`** — an iframe widget for a page you control.
- **`/badge/<slug>/<monitor>/<kind>.svg`** — a picture, for a README, where every
  Markdown renderer strips an iframe.

Both are as public as the status page they belong to, and both report the same
state the page reports. See [Embeds and badges](/guide/embeds-and-badges).
