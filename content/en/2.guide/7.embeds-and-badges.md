Both surfaces show one monitor of a **published** status page, and both are as
public as that page is. Neither carries a secret, and neither exists for a page
that is not published.

## Embed a widget

```html
<iframe src="https://status.example.com/embed/<slug>/<monitorId>"
        width="100%" height="120" frameborder="0"></iframe>
```

The admin UI generates the snippet for you under the status page's **Embed** tab.

![The embed tab: monitor, view and theme, with the generated iframe snippet and a live preview](/screenshots/en/embed.jpg)

## Use a badge in a README

Every Markdown renderer worth the name strips an iframe, so a badge is an
`<img>`: no script, no refresh, no interaction.

```
https://status.example.com/badge/<slug>/<monitorId>/<kind>.svg
```

```markdown
![API](https://status.example.com/badge/public/3/status.svg)
```

### Pick a kind

| Kind | What it draws |
| --- | --- |
| `status` | Shields-shaped: a grey label and a coloured value. |
| `uptime` | The same shape, showing the uptime figure. |
| `response` | The same shape, showing the response time. |
| `live` | One pill with a coloured dot. |
| `live-animated` | The same, pulsing. |
| `heartbeat` | The status page's heartbeat bar, shrunk to 30 bars. |

A URL that names no known kind is a `404`, not a default badge. Answering a typo
with a picture that looks right and says something else would be worse.

### Tune it

| Query parameter | Values | Default |
| --- | --- | --- |
| `style` | `flat`, `flat-square`, `plastic` | `flat` |
| `theme` | `dark`, `light` | `dark` |
| `lang` | `en`, `de` | `en` |

```markdown
![API](https://status.example.com/badge/public/3/heartbeat.svg?theme=light&style=flat-square)
```

::note
A badge lands on somebody else's page and cannot read what it sits on, so the
theme is a decision the snippet carries rather than something the badge detects.
The language works the same way, and English is the default because that is what
a README is written in.
::

### Know the caching

A badge is served with a deliberately short cache lifetime — 60 seconds. The
picture *is* the status, and an image proxy that holds it for an hour reports an
outage that ended.

Labels longer than 32 characters are ellipsized: an SVG has no layout engine, so
every width is computed from a character table and baked in.

::tip
A badge and an embed for the same monitor always agree. They read the same
state through the same code, because a badge that says green next to an embed
that says red is worse than either alone.
::
