| Method | Path | Scope |
| --- | --- | --- |
| `GET` | `/api/v1/incidents` | `incidents:read` |
| `POST` | `/api/v1/incidents` | `incidents:write` |
| `GET` | `/api/v1/incidents/{id}` | `incidents:read` |
| `PATCH` | `/api/v1/incidents/{id}` | `incidents:write` |
| `DELETE` | `/api/v1/incidents/{id}` | `incidents:write` |
| `POST` | `/api/v1/incidents/{id}/updates` | `incidents:write` |
| `PATCH` | `/api/v1/incidents/{id}/updates/{updateId}` | `incidents:write` |

Filters on the list route: `status`, `statusPageId`.

Statuses are `investigating`, `identified`, `monitoring` and `resolved`.

## Open one

An incident always has at least one timeline entry, so `message` is required on
creation.

```bash [Terminal]
curl -X POST https://status.example.com/api/v1/incidents \
  -H "Authorization: Bearer $UPCORE_KEY" -H 'Content-Type: application/json' \
  -d '{
        "title": "Elevated error rates on the API",
        "message": "We are investigating increased 5xx responses.",
        "statusPageIds": [1],
        "monitors": [{ "monitorId": 3, "impact": "degraded" }]
      }'
```

## Move the status

::caution
The status is moved by **posting a timeline update**, not by `PATCH`. A `PATCH`
changes the title, the status pages and the affected monitors.
::

```bash [Terminal]
curl -X POST https://status.example.com/api/v1/incidents/7/updates \
  -H "Authorization: Bearer $UPCORE_KEY" -H 'Content-Type: application/json' \
  -d '{ "status": "identified", "message": "A bad deploy caused the errors." }'
```

```bash [Terminal]
curl -X POST https://status.example.com/api/v1/incidents/7/updates \
  -H "Authorization: Bearer $UPCORE_KEY" -H 'Content-Type: application/json' \
  -d '{ "status": "resolved", "message": "Rolled back, error rates are normal." }'
```

Posting `resolved` stamps `resolvedAt`. Posting any other status afterwards
clears it again — which is how an incident is reopened.

## Correct an update

```bash [Terminal]
curl -X PATCH https://status.example.com/api/v1/incidents/7/updates/12 \
  -H "Authorization: Bearer $UPCORE_KEY" -H 'Content-Type: application/json' \
  -d '{ "message": "A bad deploy caused the errors; rollback in progress." }'
```
