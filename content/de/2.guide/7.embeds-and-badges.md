Beide Oberflächen zeigen einen Monitor einer **veröffentlichten** Statusseite, und
beide sind so öffentlich wie diese Seite. Keine trägt ein Geheimnis, und keine
existiert für eine Seite, die nicht veröffentlicht ist.

## Ein Widget einbetten

```html
<iframe src="https://status.example.com/embed/<slug>/<monitorId>"
        width="100%" height="120" frameborder="0"></iframe>
```

Das Admin-UI erzeugt das Snippet für dich unter dem Tab **Embed** der
Statusseite.

![Der Embed-Tab: Monitor, Ansicht und Erscheinungsbild, dazu der erzeugte iframe-Schnipsel und eine Vorschau](/screenshots/de/embed.jpg)

## Ein Badge in einer README nutzen

Jeder Markdown-Renderer, der etwas taugt, entfernt ein iframe — ein Badge ist
deshalb ein `<img>`: kein Skript, kein Refresh, keine Interaktion.

```
https://status.example.com/badge/<slug>/<monitorId>/<kind>.svg
```

```markdown
![API](https://status.example.com/badge/public/3/status.svg)
```

### Eine Art wählen

| Art | Was gezeichnet wird |
| --- | --- |
| `status` | Shields-Form: ein graues Label und ein farbiger Wert. |
| `uptime` | Dieselbe Form mit dem Uptime-Wert. |
| `response` | Dieselbe Form mit der Antwortzeit. |
| `live` | Eine Pille mit farbigem Punkt. |
| `live-animated` | Dieselbe, pulsierend. |
| `heartbeat` | Der Heartbeat-Balken der Statusseite, auf 30 Balken geschrumpft. |

Eine URL, die keine bekannte Art benennt, ist ein `404`, kein Standard-Badge.
Einen Tippfehler mit einem Bild zu beantworten, das richtig aussieht und etwas
anderes sagt, wäre schlimmer.

### Es anpassen

| Query-Parameter | Werte | Standard |
| --- | --- | --- |
| `style` | `flat`, `flat-square`, `plastic` | `flat` |
| `theme` | `dark`, `light` | `dark` |
| `lang` | `en`, `de` | `en` |

```markdown
![API](https://status.example.com/badge/public/3/heartbeat.svg?theme=light&style=flat-square)
```

::note
Ein Badge landet auf einer fremden Seite und kann nicht lesen, worauf es sitzt —
das Theme ist deshalb eine Entscheidung, die das Snippet trägt, statt etwas, das
das Badge erkennt. Mit der Sprache ist es genauso, und Englisch ist der Standard,
weil eine README so geschrieben ist.
::

### Das Caching kennen

Ein Badge wird mit bewusst kurzer Cache-Dauer ausgeliefert — 60 Sekunden. Das Bild
*ist* der Status, und ein Image-Proxy, der es eine Stunde hält, meldet eine
Störung, die vorbei ist.

Labels länger als 32 Zeichen werden gekürzt: ein SVG hat keine Layout-Engine, also
wird jede Breite aus einer Zeichentabelle berechnet und fest eingebacken.

::tip
Ein Badge und ein Embed desselben Monitors stimmen immer überein. Sie lesen
denselben Zustand durch denselben Code — denn ein Badge, das grün sagt, neben
einem Embed, das rot sagt, ist schlimmer als jedes von beiden allein.
::
